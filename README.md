### 📥 How to Use / Panduan Penggunaan

#### 1. Install the Patch (`imported_patch.yml`):
* Make a backup of your existing `imported_patch.yml`.
* Copy `imported_patch.yml` from the archive into your RPCS3 patches directory:
  * **OPETERNAL:** `<Drive>:\OPETERNAL\_app\patches\imported_patch.yml` (and `RPCS3\portable\patches\`)
  * **Standard RPCS3:** `<RPCS3_Folder>\patches\imported_patch.yml`
* In RPCS3, right-click the game -> **Manage Game Patches**, and make sure the patch is **CHECKED / ENABLED**.

#### 2. Unlock Missions & Raids (`Universal_Raid_Trainer.exe`):
1. Launch the game in RPCS3 and enter the **Online Co-op** menu.
2. Create a new Room / Lobby.
3. Open `Universal_Raid_Trainer.exe` (**Run as Administrator**).
4. Select delay time (recommended: 5 or 8 seconds) and wait for the process to finish.
5. Return to the game, open the room mission/map list: all stages and Special Raids are now unlocked!
6. Select your plane, ready up, and Sortie solo!
